How to use monitor.sh and timesheet.sh: Go into terminal and make your way into the scripts directory inside of Lab_5_workspace. Then, use ./monitor.sh. This will log the VMs uptime, memory usage, and disk usage inside a file called system.log inside the logs directory. Keep in mind though that the VM has been set up to execute monitor.sh automatically every minute. To use timesheet.sh go into the scripts directory and use ./timesheet.sh. After doing that you will be asked to enter your first and last name, the hours you worked, and a description of your work. Once you entered your responses the system will log that information into a file called timesheet.log inside the log directory.
